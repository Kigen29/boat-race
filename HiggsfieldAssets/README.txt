Scripts/fetch_assets.sh downloads the Higgsfield-generated source files here:

  SM_Boat.glb         3D boat model
  T_Title.png         menu background
  T_WaterNormal.png   water ripple normal map
  boat_reference.png  the image the boat model was made from (not imported)

Scripts/import_assets.sh then imports them into Content/Higgsfield.
To swap in a different model or image, replace the file here (same name) and
run Scripts/import_assets.sh again.
