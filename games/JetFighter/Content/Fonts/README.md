# HUD font provenance

Rajdhani Regular and SemiBold were downloaded from the official Google Fonts
repository on 20 November 2026:

- https://github.com/google/fonts/tree/main/ofl/rajdhani
- https://raw.githubusercontent.com/google/fonts/main/ofl/rajdhani/Rajdhani-Regular.ttf
- https://raw.githubusercontent.com/google/fonts/main/ofl/rajdhani/Rajdhani-SemiBold.ttf

Copyright and redistribution terms are preserved in OFL.txt (SIL Open Font
License 1.1). No font modification was made. These source files are staged as
UFS content for runtime loading; the HUD creates a runtime UFont with Regular
and Bold entries. Rajdhani is our chosen font, not an assertion about the
font used in Sky Warriors.
